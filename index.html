02Generative AI platformPublished research

Mentesa

A no-code platform for building multi-bot LLM agents.

Businesses create bots with persistent memory that answer from their own website and documents, then embed them anywhere with one line of code. I founded it and lead development on a three-person team. The research behind it was published in IJSREM in 2025, and the chat assistant in the corner of this page is a Mentesa bot.

  • Backend retrieval pipeline in Python, FastAPI and FAISS, with unit tests on the core retrieval and memory components.
  • Multi-bot admin dashboard in Streamlit, iterated on from user feedback.

Python · FastAPI · LangChain · FAISS · Gemini API · Firebase · Streamlit

03AI chatbot500+ users

ChatDouble

An AI that texts like a specific person.

Upload a WhatsApp or Instagram chat and talk to a bot that mirrors that person's tone and phrasing. It uses FAISS-based contextual retrieval over the chat history and the Gemini API to respond.

  • Retrieval and response-generation components, unit-tested, then wired into a Streamlit front end.
  • Used by more than 500 real people.

Python · Gemini API · FAISS · Streamlit
